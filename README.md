`Delhi.do` Tests weather the temperature after rain comes back to the average after one day or two days, the accompanying dta file is Stats_proj_delhi.dta\
`Shimla.do` Tests if weather has been following a normal distribution and there after we use T-test to see if the temperatures have been changing over the years\
`Geometric.do` Tests if the amount of rain follows a geometric distibution\
`Report` Is a report on Shimla.do and Geometric.do\
`Presentation` Is a presentation on Shimla.do Geometric.do as well as Negative binomial for rainfall which is also in Shimla.do and an attempt at using poison to model the rain\
`temperature_probs.jl` Uses the probabilities derived to allow interactive visual display of probabilities to see when is the best time to go to Shimla\
